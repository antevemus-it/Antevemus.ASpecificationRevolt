# 🗺️ Roadmap

- [x] **v1.0.0**: `RevoltDataSource` and `RevoltStageTransport`, the Revolt/Fibers satellite of milestone 15b of the [ASpecification roadmap](https://github.com/antevemus-it/Antevemus.ASpecification/blob/main/ROADMAP.md), on the `IDeferredDataSource`/`IStageTransport` hook of ASpecification 2.6.0: the non-HTTP requests of a resolution stage run together, each closure in its own Fiber, with `maxConcurrency` (8 by default; a shared transport or one per source), the time limit of each source, the resolution deadline cancelling what is unfinished, and the core's own failures (`sourceFailed()`, `timeout()`, `resolutionTimeout()`, `DataPendingException` as it is). `RevoltRunner`, the concurrency limit with a per-task time limit, copied from `antevemus/alinq-revolt`.
- [ ] **No HTTP source of its own (out of scope):** an Amp http-client source would duplicate the core's `HttpDataSource`, whose `curl_multi` batch already fetches HTTP concurrently with no dependency and under PHP-FPM; a closure of `RevoltDataSource` can call the Amp HTTP client when its features are needed.
- [ ] **No retries nor circuit breaker here:** they belong to the core, with its milestone 16, for every kind of source at once; a closure can retry on its own meanwhile.

The milestone view of this list lives in [ROADMAP.md](https://github.com/antevemus-it/Antevemus.ASpecificationRevolt/blob/main/ROADMAP.md).
